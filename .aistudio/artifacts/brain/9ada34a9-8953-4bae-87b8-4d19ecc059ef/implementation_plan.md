# ระบบแตกงานย่อยอัตโนมัติด้วยเทมเพลต (One-Click Subtask Templates Upgrade)

แผนงานอัปเกรดระบบควบคุมหน้างานอู่ซ่อมรถเพื่อเพิ่มฟีเจอร์ **"One-Click Subtask Templates"** ตามที่คุณได้ปรึกษาและเลือกแนวทางในการตอบคำถาม:
> *เมื่อ Controller สร้างใบงานซ่อมหลัก ระบบจะมีปุ่มคลิกเลือก "ประเภทงานหลักสำเร็จรูป" ซึ่งจะดึงชุดเทมเพลตงานย่อยมาตรฐานพร้อมเวลากลาง (StandardMinutes) ออกมาจัดเตรียมให้ทันทีใน 1 คลิก ช่วยให้ Controller ทำงานได้รวดเร็วขึ้นกว่า 10 เท่า และช่วยให้ช่างเห็นขั้นตอนลำดับการทำงานที่ชัดเจนโดยไม่ต้องพิมพ์ชื่อชิ้นงานเองหน้างาน*

---

## User Review & Critical Decisions

> [!IMPORTANT]
> การอัปเกรดนี้จะเป็นการปรับโครงสร้างระบบให้ฉลาดขึ้นและขจัดภาระการคีย์ข้อมูลของทั้ง Controller และช่าง โดยข้อมูลทั้งหมดจะคงความสมบูรณ์แบบ 100% เพื่อใช้วิเคราะห์ประสิทธิภาพเชิงลึก

- **การเพิ่มปุ่มดึงเทมเพลตในหน้าสร้าง Job**: ในฟอร์มสร้าง Job ของ Controller จะเพิ่มตัวเลือกประเภทเทมเพลต (เช่น งานทำสีแผง/เฉพาะจุด, งานทำสีรอบคัน, งานเช็กระยะรถยนต์, งานซ่อมช่วงล่าง & เบรก) เมื่อคลิกเลือก ระบบจะกรอกรายการงานย่อยทั้งหมด วันเริ่มต้น วันกำหนดส่ง และเวลามาตรฐานกลางให้อัตโนมัติทันที
- **การเพิ่มชุดข้อมูลเทมเพลตในชีต Settings**: เราจะอัปเกรดข้อมูลในชีต `Settings` ให้เก็บโครงสร้างเทมเพลตมาตรฐานเพื่อให้ผู้จัดการอู่สามารถไปแก้ไขขั้นตอนและเวลามาตรฐานกลางของแต่ละอู่ได้เองในอนาคตผ่านหน้าจอแอปพลิเคชัน
- **ช่างทำงานง่ายขึ้น**: ช่างไม่จำเป็นต้องพิมพ์รายละเอียดใดๆ เพียงดูคิวงานตามลำดับเทมเพลตที่เป็นระเบียบเรียบร้อย แล้วกดเริ่มงานพักงานตามปกติ

---

## 1. Overview & Core Concept

- **What It Does**: อัปเกรดหน้าจอสร้างใบงาน (Jobs Manager) ให้รองรับการนำชุดขั้นตอนการทำงานซ่อมมาตรฐาน (Standard Operation Procedures — SOP) มาสร้างเป็นงานย่อยอัตโนมัติ ช่วยลดเวลาของ Controller ในการพิมพ์รายละเอียดเดิมๆ ซ้ำๆ และลดความเสี่ยงที่ข้อมูลชื่อขั้นตอนการทำงานจะบันทึกไม่เหมือนกัน
- **Standard Templates** ที่จะถูกติดตั้งมากับระบบในคลิกเดียว:
  1. **งานทำสีรถยนต์เฉพาะจุด (Panel Paint Job)**:
     - 1. ถอดชิ้นส่วนจัดเตรียมพื้นผิว / เคาะแต่งเหล็ก (60 นาที)
     - 2. โป๊วสี / ขัดผิวเรียบ (90 นาที)
     - 3. พ่นสีพื้นเกาะเหล็ก / สีพื้น 2K (60 นาที)
     - 4. พ่นสีจริง / พ่นเคลือบเงาแลคเกอร์ (90 นาที)
     - 5. ขัดสีเก็บรายละเอียด / ประกอบชิ้นส่วน (60 นาที)
  2. **งานทำสีรอบคัน (Full Car Paint Job)**:
     - 1. ถอดประกอบและขัดลอกฟิล์มสีเดิมทั้งคัน (180 นาที)
     - 2. เคาะผุ / ดึงตัวถังให้ได้รูป (120 นาที)
     - 3. โป๊วสีรอบคัน / ลูบน้ำขัดแห้งละเอียด (240 นาที)
     - 4. พ่นสีรองพื้นกันสนิม / สีพื้น 2K อบอุณหภูมิ (180 นาที)
     - 5. พ่นสีจริงรอบคัน / พ่นแลคเกอร์และอบห้องสีมาตรฐาน (240 นาที)
     - 6. ขัดยาเงาผิวส้ม / ประกอบอุปกรณ์ตกแต่งและตรวจความสะอาด (180 นาที)
  3. **งานเช็กระยะ 100,000 กม. / ซ่อมทั่วไป (Periodic Maintenance)**:
     - 1. ถ่ายน้ำมันเครื่อง / น้ำมันเกียร์ / ของเหลวครบชุด (45 นาที)
     - 2. ถอดล้างลิ้นปีกผีเสื้อ / ตรวจเช็กระบบไฟผ่านเครื่อง OBD (30 นาที)
     - 3. ตรวจเช็กสภาพหัวเทียน / สายพานหน้าเครื่อง / ไส้กรองแอร์ (30 นาที)
     - 4. ตรวจเช็กความแน่นลูกหมากช่วงล่าง / บูชปีกนกและทดลองขับ (45 นาที)

## 2. User Experience & Visual Design

- **UI & Flow ในหน้า Jobs Manager**:
  - เพิ่มส่วน **"เทมเพลตงานด่วน (Quick SOP Templates)"** ไว้ด้านบนสุดของส่วนแตกงานย่อยในฟอร์มสร้าง Job
  - มีปุ่มตัวเลือกแบบไอคอน เช่น 🎨 *ทำสีเฉพาะจุด* · 🚗 *ทำสีรอบคัน* · 🔧 *เช็กระยะ 100K* · ⚙️ *ซ่อมระบบเบรก*
  - เมื่อ Controller กดปุ่มเทมเพลตเหล่านี้ ฟิลด์รายการย่อยทั้งหมดจะถูกสร้างและเขียนคำอธิบาย รวมถึงกำหนดเวลามาตรฐาน (`StandardMinutes`) ให้อัตโนมัติทันที
  - Controller สามารถแก้ไขรายชื่อช่างผู้รับ 책임 หรือปรับแต่งชื่อ Task และเวลามาตรฐานเป็นรายกรณีได้ก่อนกดบันทึก ช่วยให้ระบบยืดหยุ่นสูงมาก

- **UI & Flow ในหน้าจอช่าง (Technician)**:
  - ช่างจะเห็นคิวงานย่อยเรียงลำดับตามขั้นตอน SOP 1, 2, 3, 4, 5 อย่างสวยงาม ชัดเจน และมีมาตรฐานเป็นหนึ่งเดียวกัน
  - ช่วยให้ช่างทราบล่วงหน้าว่าใครเป็นคนทำขั้นตอนก่อนหน้าของรถคันนี้ (เช่น ขั้นตอนเคาะเสร็จแล้ว ช่างขัดก็รู้สถานะแล้วเริ่มงานต่อได้เลย)

## 3. Technical Architecture & Data Strategy

### ชุดข้อมูลเทมเพลตที่จะอัปเดตลง Settings Sheet:

เราจะเพิ่ม Config Key ในชีต Settings เพื่อเก็บข้อมูลเทมเพลตสำเร็จรูป:
- `TEMPLATE_PAINT_PANEL`: ขั้นตอนและเวลามาตรฐานงานทำสีเฉพาะจุด
- `TEMPLATE_PAINT_FULL`: ขั้นตอนและเวลามาตรฐานงานทำสีรอบคัน
- `TEMPLATE_MAINTENANCE_100K`: ขั้นตอนและเวลามาตรฐานงานเช็กระยะ 100,000 กม.
- `TEMPLATE_BRAKE_SYSTEM`: ขั้นตอนและเวลามาตรฐานงานระบบเบรก

### ตัวอย่างการจำลองการทำงานบนหน้าเว็บและการอัปเกรดใน Code.gs:

เราจะเขียนชุดข้อมูลเทมเพลตมาตรฐานในไฟล์ `src/data/initialSheetsData.ts` และอัปเกรดหน้าจอสร้างใบงานซ่อมใน `src/components/JobsManagerView.tsx` ให้มีตัวเลือก SOP Templates รวมถึงอัปเดตไฟล์เทมเพลต `Code.gs` และ `Index.html` ให้รองรับระบบเทมเพลตอัตโนมัติแบบ 1 คลิกนี้ด้วย เพื่อให้โค้ดดาวน์โหลดที่ผู้ใช้นำไปใช้จริงมีความสามารถนี้ติดตัวไปด้วยเลยครับ!
