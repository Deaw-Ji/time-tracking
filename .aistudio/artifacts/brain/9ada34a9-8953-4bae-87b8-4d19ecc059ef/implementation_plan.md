# บันทึกการเพิ่มระบบติดตามกำหนดการทำงานและแก้ไขวันกำหนดช่าง (Task Schedule & Adherence System)

## สรุปการแก้ไขและฟังก์ชันที่เพิ่มเข้ามาตามคำขอของผู้ใช้

### 1. รายละเอียดใบงานซ่อมสี (Job Sheet Detail Modal)
- **เพิ่มคอลัมน์ "กำหนดการช่าง & ติดตามเริ่มงาน"**:
  - แสดงวันกำหนดเริ่ม (`StartDate`) และวันกำหนดเสร็จ (`DueDate`) ของแต่ละขั้นตอนงานย่อย
  - แสดง Badge วิเคราะห์การเริ่มงานจริงเทียบกับแผน:
    - **เริ่มตรงกำหนด**: สีเขียว Emerald แสดงวันที่ช่างเริ่มงานจริงตรงตามแผน
    - **เริ่มก่อนกำหนด**: สีฟ้า Blue แสดงจำนวนวันที่เริ่มก่อนแผน
    - **เริ่มช้ากว่ากำหนด**: สีส้ม Amber แสดงจำนวนวันที่เริ่มล่าช้ากว่าแผน
    - **เลยกำหนดเริ่มแล้ว**: สีแดง Rose (กระพริบเตือน) หากยังไม่เริ่มและเลยกำหนดวันที่ Controller วางไว้
    - **เสร็จตามแผน / เกินกำหนดเสร็จ**: แจ้งเตือนเมื่อใกล้ถึงหรือเกินกำหนดส่งมอบขั้นตอน
- **ปุ่มแก้ไขกำหนดการ (Edit Schedule Modal)**:
  - Controller สามารถกดไอคอนดินสอ/ปฏิทินที่ขั้นตอนย่อยเพื่อเปิดหน้าต่าง **"แก้ไขวันกำหนดให้ช่างทำงาน"** ได้ตลอดเวลา
  - มีช่องเลือกวันที่กำหนดเริ่ม (`Target Start Date`) และวันที่กำหนดเสร็จ (`Target Due Date`)
  - มีปุ่มทางลัดด่วน: *เริ่มวันนี้*, *เสร็จภายในวันนี้*, *เสร็จตามใบงานหลัก*
  - มีการตรวจสอบความถูกต้อง (วันเสร็จต้องไม่มาก่อนวันเริ่ม)
  - ซิงค์บันทึกข้อมูลลงฐานข้อมูล Firebase Firestore ทันที พร้อมแสดง Toast แจ้งเตือน

### 2. หน้าจอช่างซ่อมตัวถังและสี (Technician Floor View)
- **ตารางงานที่กำลังดำเนินการ (In Progress Tasks)**:
  - เพิ่มคอลัมน์แสดงช่วงวันที่กำหนดเริ่ม - กำหนดเสร็จ
  - แสดง Badge ติดตามการเริ่มงานจริงของช่าง (เริ่มตรงกำหนด, เริ่มก่อนกำหนด, หรือเริ่มล่าช้า)
- **ตารางงานที่รอดำเนินการ (Pending Tasks)**:
  - แสดง Badge เตือนความเร่งด่วน: *เลยกำหนดเริ่ม X วัน*, *ครบกำหนดเริ่มวันนี้*, หรือ *ตามแผนงาน*
- **หน้าจอทำงานเฉพาะคัน (Task Focus Workstation)**:
  - เพิ่มแถบแสดงสถานะความตรงต่อเวลาและการส่งมอบเทียบกับ SLA อย่างชัดเจน

### 3. ตารางสถานะขั้นตอนทำสีรถยนต์ย่อยทั้งหมด (Live SOP Progress Matrix บน Dashboard)
- เพิ่มคอลัมน์ **"กำหนดการ & ติดตามเริ่มงาน"** เพื่อให้ผู้บริหารและ Controller สามารถกวาดสายตามองเห็นสถานะความคืบหน้าและความตรงต่อเวลาของทุกขั้นตอนในศูนย์ซ่อมได้ทันที
